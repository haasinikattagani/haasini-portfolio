01

Twixt Game

C
Developed a command-line based Twixt game in C, implementing a grid-based board using a 2D array where each cell represents an empty, Red, or Black state. The game supports user-defined board sizes and interactive commands such as new, place, and show. Move validation ensures that markers are placed only in valid and unoccupied cells. Implemented connection logic based on chess-like knight moves. Winning conditions are defined such that Red connects top to bottom and Black connects left to right. Used recursion to explore paths by tracking visited cells and identifying valid connections; a win is detected when a path reaches the target edge. This project was completed as part of a first-semester C programming course and helped develop skills in recursion, condition handling, structured programming, and step-by-step problem solving. It also highlighted the trade-off between efficient logic implementation in C and limited user interactivity in CLI systems, with scope for improvements in modularity, efficiency, additional command-line features, and transitioning to a GUI-based interface.
02

Music Unplugged

C
Developed a command-line based music management system in C that handles albums, songs, and playlists. Implemented data organization using structures and linked lists, with albums stored in a linked list and dynamic memory allocation used for creating new entries. Incorporated string comparison for searching albums and enabled grouping of songs into albums and playlists. This project was completed as an end of semester C programming assignment and strengthened my understanding of linked lists , structures, memory management, and structured code organization. It also provided insight into how real-world music collections are managed. The implementation highlights the efficiency and control offered by linked lists and CLI-based systems, while also exposing limitations such as manual memory handling and limited user interaction without a GUI, with scope for improvements like enhanced UI, search, and filtering features.
03

Google Clone

JavaScript HTML & CSS
Developed a front-end web application as part of an Introduction to Software Systems course using HTML, CSS, and JavaScript. The project replicates a simplified Google-like interface, featuring a structured layout with navigation links, a search bar, and a footer section. Implemented user interaction through JavaScript, including input handling, a character counter with a maximum limit, and dynamic enabling/disabling of the search button. The application demonstrates fundamental concepts of web development such as DOM manipulation, event handling, and responsive UI structuring. This project helped build a strong foundation in designing interactive user interfaces and integrating functionality across HTML, CSS, and JavaScript.
04

1D random walk model

Python
Developed a Python-based simulation of a single electron trajectory using a 1D random walk model as part of a Computing in Sciences course. The implementation uses NumPy for random number generation and simulates the electron’s motion by iteratively updating its position with fixed step sizes in positive or negative directions based on probabilistic outcomes. Multiple trajectories are generated to analyze variation in motion, and the results are visualized using Matplotlib through line plots and a histogram of positions. The project demonstrates the use of arrays, loops, and stochastic modeling to simulate physical behavior, and helped build understanding of random processes, numerical simulation, and data visualization in Python.
